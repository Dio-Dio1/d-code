# D:Code

A competitive coding platform where developers duel head-to-head in real time.
Think LeetCode meets a fighting game — timed, live, and against a real opponent.

## Stack

- React 19 + Vite 8
- Tailwind CSS v4
- lucide-react icons

## Getting Started

```bash
npm install
npm run dev
```

## What's built

- Sidebar navigation and dashboard
- Problems page — search, difficulty filters, topic tags
- Leaderboard — global, friends, and weekly tabs with tier badges
